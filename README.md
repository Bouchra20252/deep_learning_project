# Deep Learning Projects

A collection of deep learning projects developed using Python and PyTorch.
This repository explores different neural network architectures and their
applications in classification and natural language processing.

## Projects

### 1. MLP — Breast Cancer Classification

A Multi-Layer Perceptron (MLP) designed to classify breast cancer cases
based on numerical features.

- **Architecture:** Multi-Layer Perceptron (MLP)
- **Task:** Binary Classification
- **Framework:** PyTorch
- **Domain:** Healthcare

### 2. CNN — MNIST Digit Classification

A Convolutional Neural Network (CNN) trained to recognize handwritten
digits from the MNIST dataset.

- **Architecture:** Convolutional Neural Network (CNN)
- **Task:** Image Classification
- **Dataset:** MNIST
- **Input:** 28 × 28 grayscale images
- **Classes:** 10 digits (0–9)
- **Framework:** PyTorch
- **Domain:** Computer Vision

### 3. RNN — Text Generation

A Recurrent Neural Network (RNN) developed to learn patterns from
sequential text data and generate new text sequences.

- **Architecture:** Recurrent Neural Network (RNN)
- **Task:** Text Generation
- **Framework:** PyTorch
- **Domain:** Natural Language Processing
